# TC-PRO-B1-P.Final
Realicé una aplicación en MIT App Inventor, la cual por medio de un ChatBot, hará predicciones sobre el impacto del cambio climático en la agricultura, ya que el cambio climático tiene un profundo impacto en la agricultura mundial, afectando el rendimiento de los cultivos, la salud del suelo y la sostenibilidad agrícola.
